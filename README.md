# VareFacil — frontend

## Dev

```bash
npm install
npm run dev
```

Abre em `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```

## Stack

React + Vite · Tailwind v4 · Urbanist · Phosphor (`@phosphor-icons/react`)

Env: copiar `.env.example` → `.env.local` (`VITE_API_URL`).
